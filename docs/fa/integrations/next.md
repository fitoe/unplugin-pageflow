# Next.js

Next.js رابط افزونهٔ Vite ارائه نمی‌کند، بنابراین PageFlow از یک sidecar هم‌مبدأ ویژهٔ توسعه استفاده می‌کند.

## آماده‌سازی PageFlow

بسته را به‌عنوان وابستگی توسعه نصب کنید و مطمئن شوید برنامهٔ Next.js در حال اجراست.

```bash
pnpm add -D unplugin-pageflow
pnpm next dev
```

## اجرای sidecar

CLI را از ریشهٔ برنامه اجرا کنید:

```bash
pageflow-next --dir . --host 127.0.0.1 --port 3000
```

CLI مسیرهای فایل‌محور پشتیبانی‌شدهٔ Next.js را کشف و URLِ PageFlow را چاپ می‌کند.

## گزینه‌ها

- `--dir` پوشهٔ پروژهٔ Next.js را انتخاب می‌کند.
- `--host` میزبان توسعه را انتخاب می‌کند.
- `--port` پورت توسعهٔ Next.js مورد استفادهٔ sidecar را مشخص می‌کند.

## فقط توسعه

sidecar بخشی از `next build` نیست و سرور تولید از آن استفاده نمی‌کند. آن را در اسکریپت‌های توسعهٔ محلی نگه دارید، نه تعریف فرایند تولید.

## رفع اشکال

- پیش از بازکردن پیش‌نمایش صفحه‌ها، Next.js را اجرا کنید.
- از میزبان و پورت آزاد استفاده کنید.
- مطمئن شوید صفحه‌ها مستقیماً در همان نشست مرورگر رندر می‌شوند.
- از احراز هویت و دادهٔ محلی یا آزمایشی استفاده کنید.

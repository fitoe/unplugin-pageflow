# محدودیت‌ها و ایمنی

PageFlow هنگام توسعه صفحه‌های واقعی برنامه را رندر می‌کند. با پیش‌نمایش مانند بازدید عادی از برنامهٔ محلی رفتار کنید.

## PageFlow چه می‌کند

- مسیرهای ارائه‌شده توسط آداپتور انتخابی را کشف می‌کند.
- پیش‌نمایش صفحهٔ هم‌مبدأ را رندر می‌کند.
- پیوندها و مقصدهای ناوبری پشتیبانی‌شده را تشخیص می‌دهد.
- ناوبری لنگر و ارسال فرم را در حالت پیش‌نمایش مسدود می‌کند.
- runtime خود را از buildهای تولید بیرون نگه می‌دارد.

## PageFlow چه نمی‌کند

- احراز هویت یا مجوز را دور نمی‌زند.
- خودکار روی کنترل‌ها کلیک نمی‌کند.
- عوارض آغاز برنامه را متوقف نمی‌کند.
- همهٔ مقصدهای محاسبه‌شده را پیش از تعامل مربوطه استنتاج نمی‌کند.
- داخل islandهای فریم‌ورک Astro را بررسی نمی‌کند.

## از دادهٔ امن استفاده کنید

برای صفحه‌هایی که هنگام مقداردهی داده می‌نویسند از دادهٔ محلی یا آزمایشی استفاده کنید. رمز عبور، token، کد تأیید یا اطلاعات محرمانهٔ واقعی را به‌عنوان وضعیت پیش‌نمایش تنظیم نکنید.

احراز هویت و وضعیت ویژهٔ مسیر از نشست فعلی مرورگر می‌آیند. صفحهٔ بدون مجوز ممکن است نمای عادی ورود یا عدم دسترسی را رندر کند.

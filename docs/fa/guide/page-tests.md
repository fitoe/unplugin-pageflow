# آزمون‌های صفحه

PageFlow می‌تواند مسیرها را با آزمون‌های واحد، مؤلفه و سرتاسری مرتبط کند و فرمان‌های صریحاً تنظیم‌شده را از صفحهٔ انتخابی اجرا کند.

## ارتباط خودکار

اگر آزمون یک مؤلفهٔ صفحه را import کند، از قرارداد نام یکسان پیروی کند یا در مورد آزمون به مسیر کامل برود، مرتبط می‌شود. PageFlow دلیل هر ارتباط را نشان می‌دهد.

## نگاشت صریح

وقتی ارتباط خودکار مبهم است از glob مسیر و فایل استفاده کنید.

```ts
PageFlow.vite({
  pageTests: {
    '/orders/**': ['tests/orders-*.spec.ts'],
  },
})
```

## فرمان‌های آزمون

هیچ فرمانی به‌طور پیش‌فرض حدس زده یا فعال نمی‌شود. هر نوع آزمون پشتیبانی‌شده را صریحاً تنظیم کنید.

```ts
PageFlow.vite({
  testCommands: {
    unit: {
      command: 'pnpm',
      args: ['vitest', 'run', '{file}', '-t', '{name}'],
    },
    component: {
      command: 'pnpm',
      args: ['vitest', 'run', '{file}', '-t', '{name}'],
    },
    e2e: {
      command: 'pnpm',
      args: ['playwright', 'test', '{file}', '-g', '{name}'],
      timeoutMs: 180_000,
    },
  },
})
```

`{file}` و `{name}` با مقادیر فهرست‌شده جایگزین می‌شوند. فرمان‌ها از ریشهٔ پروژه با `shell: false` اجرا می‌شوند. مهلت پیش‌فرض ۱۲۰ ثانیه است؛ `timeoutMs` از ۱ ثانیه تا ۳۰ دقیقه را می‌پذیرد.

## نتایج

پنل صفحه وضعیت‌های ناشناخته، در حال اجرا، موفق، ناموفق، ردشده یا لغوشده را نشان می‌دهد. آزمون در حال اجرا را می‌توان از PageFlow لغو کرد. خروجی آزمون فقط در توسعه می‌ماند و هرگز در bundle تولید قرار نمی‌گیرد.

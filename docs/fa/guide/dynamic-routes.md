# مسیرهای پویا

مسیری مانند `/products/:id` تا زمانی که PageFlow مقدار امنی برای `id` نداند قابل رندر نیست. مقادیر نماینده را با `dynamicParams` تنظیم کنید.

```ts
PageFlow.vite({
  dynamicParams: {
    '/products/:id': { id: 'demo-product' },
    '/users/:userId/orders/:orderId': {
      userId: 'alice',
      orderId: 'order-100',
    },
  },
})
```

## تطبیق

الگوی مسیر ارائه‌شده توسط آداپتور فریم‌ورک را به‌عنوان کلید شیء استفاده کنید. هر پارامتر نام‌گذاری‌شدهٔ موردنیاز باید مقدار داشته باشد.

## رشته‌های پرس‌وجو و هش‌ها

PageFlow رشته‌های پرس‌وجو و هش‌های کشف‌شده را به‌عنوان موقعیت ناوبری نگه می‌دارد. آن‌ها می‌توانند زبانه، فیلتر یا لنگر را نمایش دهند، درحالی‌که مسیر زیرین یکسان است.

```text
/products/demo-product?tab=history#activity
```

## انتخاب مقادیر نمونه

از شناسه‌های پایدار مبتنی بر fixture محلی یا دادهٔ آزمایشی استفاده کنید. از شناسهٔ مشتری واقعی و صفحه‌هایی که هنگام مقداردهی نوشتن برگشت‌ناپذیر انجام می‌دهند دوری کنید.

پارامترهای پویا فقط URL می‌سازند. آن‌ها احراز هویت، مجوز، loader یا اعتبارسنجی برنامه را دور نمی‌زنند.

## رفع اشکال

اگر صفحهٔ پویا هنوز رندر نمی‌شود:

1. بررسی کنید کلید تنظیم‌شده دقیقاً با الگوی مسیر فریم‌ورک یکسان باشد.
2. همهٔ پارامترهای لازم را ارائه کنید.
3. URL ساخته‌شده را مستقیماً در همان نشست مرورگر باز کنید.
4. بررسی کنید احراز هویت یا loader درخواست را هدایت مجدد نکند.

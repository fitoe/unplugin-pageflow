# 大規模プロジェクトとキャッシュ

PageFlow はすべてのルートを同時にライブ文書として描画しません。描画とキャッシュに上限を設け、大きなグラフでも探索可能にします。

## ビューポート描画

近くの DOM プレビューと LeaferJS オブジェクトだけをマウントします。遠いページは軽量表示を使い、選択された一ページだけをライブ iframe にします。

## サムネイル階層

近いページには詳細プレビュー、遠いページには小さな WebP サムネイルを使います。長いページは表示範囲単位のタイルに分割できます。再キャプチャ中も古いサムネイルを表示します。

## キャプチャキュー

フォント、画像、DOM の安定を待ってから、一度に一ページずつキャプチャします。選択中と表示中のページを優先します。

## レイアウトと検索

1,000 ページを超えるグラフは Worker へレイアウト処理を移せます。空間インデックスにより、毎回グラフ全体を走査せずに表示ページを見つけます。

## キャッシュ場所

```text
.unplugin-pageflow/cache
```

メモリとディスクのキャッシュには固定 LRU 上限があります。このディレクトリは削除可能な開発出力です。

## 実践的なヒント

- 意味のあるパス区間でルートをグループ化します。
- 安定した動的パラメーター例を用意します。
- fixture データでプレビューを決定的にします。
- 長い非同期処理には準備完了シグナルを使います。

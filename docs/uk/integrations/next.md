# Next.js

Next.js не надає інтерфейс Vite-плагіна, тому PageFlow використовує допоміжний процес того самого походження лише для розробки.

## Підготовка PageFlow

Установіть пакет як залежність для розробки та переконайтеся, що застосунок Next.js запущений.

```bash
pnpm add -D unplugin-pageflow
pnpm next dev
```

## Запуск допоміжного процесу

Запустіть CLI з кореня застосунку:

```bash
pageflow-next --dir . --host 127.0.0.1 --port 3000
```

CLI виявить підтримувані файлові маршрути Next.js і виведе URL-адресу PageFlow.

## Параметри

- `--dir` задає директорію проєкту Next.js.
- `--host` задає хост розробки.
- `--port` указує порт розробки Next.js, який використовує допоміжний процес.

## Лише для розробки

Допоміжний процес не є частиною `next build` і не використовується продакшн-сервером. Додавайте його до локальних сценаріїв розробки, а не до описів продакшн-процесів.

## Усунення несправностей

- Запустіть Next.js перед відкриттям переглядів сторінок.
- Використовуйте доступні хост і порт.
- Переконайтеся, що сторінки відкриваються напряму в тому самому сеансі браузера.
- Використовуйте локальні або тестові автентифікацію та дані.

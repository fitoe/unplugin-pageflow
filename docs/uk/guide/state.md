# Стан сторінки

PageFlow зберігає корисний стан попереднього перегляду, тому перехід до іншої сторінки не завжди скидає інтерфейс.

## Автоматично відновлюваний стан

Підтримувані нативні поля введення, списки, прапорці та позиції прокручування зберігаються й відновлюються автоматично. Поля паролів, файлів і кодів підтвердження навмисно виключені.

## Реєстрація стану застосунку

Складні віджети та стан фреймворку можуть підключитися через `definePageFlowState`.

```ts
import { onUnmounted, ref } from 'vue'
import { definePageFlowState } from 'unplugin-pageflow/runtime-state'

const activeTab = ref('overview')
const selectedRole = ref('farmer')

const stop = definePageFlowState('page-options', {
  get: () => ({
    activeTab: activeTab.value,
    selectedRole: selectedRole.value,
  }),
  restore: (state) => {
    activeTab.value = state.activeTab
    selectedRole.value = state.selectedRole
  },
})

onUnmounted(stop)
```

Використовуйте стабільний ключ, унікальний для блоку стану. Повертайте з `get` серіалізовані, нечутливі дані та зробіть `restore` безпечним для виклику після монтування сторінки.

## Ізоляція

Стан і кешовані перегляди ізолюються за повною URL-адресою сторінки, включно зі значущими рядками запиту та хешами, а також за роллю PageFlow, що використовується для перегляду.

## Безпека

Ніколи не реєструйте паролі, токени, коди підтвердження, приватні ключі чи секрети клієнтів. Сприймайте зареєстрований стан як дані інструмента розробки, а не захищене сховище.

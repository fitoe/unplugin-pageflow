# Динамічні маршрути

Маршрут `/products/:id` не можна відобразити, доки PageFlow не знає безпечне значення `id`. Задайте його через `dynamicParams`.

```ts
PageFlow.vite({
  dynamicParams: {
    '/products/:id': { id: 'demo-product' },
    '/users/:userId/orders/:orderId': {
      userId: 'alice',
      orderId: 'order-100',
    },
  },
})
```

## Відповідність

Ключем має бути шаблон маршруту, який надає адаптер. Укажіть усі обов’язкові іменовані параметри.

## Рядок запиту та хеш

PageFlow зберігає знайдені query-параметри й хеші як місця навігації для вкладок, фільтрів або якорів.

```text
/products/demo-product?tab=history#activity
```

## Вибір значень

Використовуйте стабільні локальні fixture або тестові дані. Не використовуйте реальні ідентифікатори клієнтів чи сторінки з незворотними записами під час запуску.

Динамічні параметри лише будують URL і не обходять автентифікацію, авторизацію, loaders або перевірку застосунку.

## Усунення проблем

1. Перевірте точний збіг шаблону.
2. Надайте всі параметри.
3. Відкрийте URL напряму в тій самій сесії.
4. Перевірте перенаправлення автентифікації або loader.

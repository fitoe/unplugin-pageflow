# Тести сторінок

PageFlow може пов’язувати маршрути з модульними, компонентними та наскрізними тестами, а потім запускати явно налаштовані команди з вибраної сторінки.

## Автоматичне зіставлення

Тест можна пов’язати зі сторінкою, якщо він імпортує її компонент, дотримується правила однакових імен або переходить до повного маршруту в тестовому сценарії. PageFlow показує причину кожного зіставлення.

## Явні зіставлення

Коли автоматичне зіставлення неоднозначне, використовуйте шаблони маршрутів і файлів.

```ts
PageFlow.vite({
  pageTests: {
    '/orders/**': ['tests/orders-*.spec.ts'],
  },
})
```

## Команди тестів

За замовчуванням жодна команда не вгадується й не вмикається. Налаштуйте кожен підтримуваний тип тестів явно.

```ts
PageFlow.vite({
  testCommands: {
    unit: {
      command: 'pnpm',
      args: ['vitest', 'run', '{file}', '-t', '{name}'],
    },
    component: {
      command: 'pnpm',
      args: ['vitest', 'run', '{file}', '-t', '{name}'],
    },
    e2e: {
      command: 'pnpm',
      args: ['playwright', 'test', '{file}', '-g', '{name}'],
      timeoutMs: 180_000,
    },
  },
})
```

`{file}` і `{name}` замінюються індексованими значеннями. Команди запускаються з кореня проєкту з `shell: false`. Типовий тайм-аут тесту становить 120 секунд; `timeoutMs` приймає значення від 1 секунди до 30 хвилин.

## Результати

Панель сторінки показує стани: невідомий, виконується, успішний, невдалий, пропущений або скасований. Запущений тест можна скасувати з PageFlow. Результати тестів стосуються лише розробки й ніколи не потрапляють у продакшн-пакет.

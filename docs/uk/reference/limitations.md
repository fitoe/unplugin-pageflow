# Обмеження та безпека

PageFlow відображає реальні сторінки застосунку під час розробки. Сприймайте перегляди як звичайні відвідування локального застосунку.

## Що робить PageFlow

- Виявляє маршрути, які надає вибраний адаптер фреймворку.
- Відображає перегляди сторінок того самого походження.
- Виявляє підтримувані посилання та цілі навігації.
- Блокує переходи за посиланнями та надсилання форм у режимі перегляду.
- Не додає своє середовище виконання до продакшн-збірок.

## Чого PageFlow не робить

- Не обходить автентифікацію чи авторизацію.
- Не натискає елементи керування автоматично.
- Не пригнічує побічні ефекти запуску застосунку.
- Не може визначити всі обчислювані цілі до відповідної взаємодії.
- Не аналізує внутрішню структуру Astro islands.

## Використовуйте безпечні дані

Для сторінок, що виконують запис під час ініціалізації, використовуйте локальні або тестові дані. Не задавайте реальні паролі, токени, коди підтвердження чи інші секрети як стан перегляду.

Автентифікація та стан конкретного маршруту беруться з поточного сеансу браузера. Сторінка без дозволу може показати звичайний екран входу або відмови в доступі.

# Сумісність

PageFlow потребує Node.js 20.19 або новішої версії. Установлюйте його як залежність для розробки.

| Інтеграція | Мінімальна версія peer dependency | Джерело маршрутів | Примітки |
| --- | --- | --- | --- |
| Vite + Vue Router | Vite 5, Vue 3.4, Vue Router 4 | `router.getRoutes()` | Повна інтеграція із середовищем розробки. |
| Nuxt | Nuxt 3 | Записи Vue Router | Розпізнає події навігації Nuxt/Vue. |
| Astro | Astro 5 | Файлові маршрути | Якорі того самого походження та `data-pageflow-to`; без аналізу islands. |
| React Router | Об’єкти маршрутів | Явні об’єкти маршрутів | Використовуйте `unplugin-pageflow/react-router`. |
| SvelteKit | SvelteKit 2 | Файлові маршрути | Адаптер поєднується із `sveltekit()`. |
| SolidStart | SolidStart | Файлові маршрути | Адаптер поєднується з плагіном Solid. |
| Qwik City | Qwik 1.10, Qwik City 1.10 | Файлові маршрути | Адаптер поєднується з Qwik City і Vite. |
| Next.js | Next.js 15 | Файлові маршрути | Використовує допоміжний процес розробки `pageflow-next`. |
| uni-app | Сучасна конфігурація на основі Vite | Створені маршрути | Лише для розробки. |

## Вимоги до браузера

Для попереднього перегляду потрібен доступ до iframe того самого походження та сучасний браузер із підтримкою стандартних API історії, повідомлень і canvas.

## Підтримка продакшену

PageFlow навмисно не має продакшн-середовища виконання. Продакшн-збірки не повинні містити його клієнт або кінцеві точки розробки.

## Політика версій

Діапазони peer dependency фреймворків описують межі підтримуваної інтеграції. Перед переходом на нові основні версії фреймворків перевірте маніфест пакета та CI.

# Ограничения и безопасность

PageFlow отображает реальные страницы приложения во время разработки. Относитесь к превью как к обычным посещениям локального приложения.

## Что делает PageFlow

- Обнаруживает маршруты, предоставляемые выбранным адаптером фреймворка.
- Отображает превью страниц того же источника.
- Находит поддерживаемые ссылки и цели навигации.
- Блокирует переходы по якорям и отправку форм в режиме превью.
- Исключает свою среду выполнения из производственных сборок.

## Чего PageFlow не делает

- Не обходит аутентификацию или авторизацию.
- Не нажимает элементы управления автоматически.
- Не подавляет побочные эффекты запуска приложения.
- Не может вывести все вычисляемые цели до соответствующего взаимодействия.
- Не анализирует внутреннее устройство Astro islands.

## Используйте безопасные данные

Для страниц, записывающих данные при инициализации, используйте локальные или тестовые данные. Не задавайте реальные пароли, токены, коды подтверждения или другие секреты как состояние превью.

Аутентификация и состояние конкретного маршрута берутся из текущей сессии браузера. Страница без разрешения может показать обычный экран входа или отказа в доступе.

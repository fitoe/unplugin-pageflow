# Совместимость

PageFlow требует Node.js 20.19 или новее. Установите его как зависимость разработки.

| Интеграция | Минимальная peer-версия | Источник маршрутов | Примечания |
| --- | --- | --- | --- |
| Vite + Vue Router | Vite 5, Vue 3.4, Vue Router 4 | `router.getRoutes()` | Полная интеграция со средой разработки. |
| Nuxt | Nuxt 3 | Записи Vue Router | Распознаёт события навигации Nuxt/Vue. |
| Astro | Astro 5 | Файловые маршруты | Якоря того же источника и `data-pageflow-to`; без внутреннего устройства islands. |
| React Router | Объекты маршрутов | Явные объекты маршрутов | Используйте `unplugin-pageflow/react-router`. |
| SvelteKit | SvelteKit 2 | Файловые маршруты | Адаптер сочетается с `sveltekit()`. |
| SolidStart | SolidStart | Файловые маршруты | Адаптер сочетается с плагином Solid. |
| Qwik City | Qwik 1.10, Qwik City 1.10 | Файловые маршруты | Адаптер сочетается с Qwik City и Vite. |
| Next.js | Next.js 15 | Файловые маршруты | Использует sidecar разработки `pageflow-next`. |
| uni-app | Современная конфигурация на Vite | Созданные маршруты | Только для разработки. |

## Требования к браузеру

Превью требуют доступа к iframe того же источника и современного браузера со стандартной поддержкой history, messaging и canvas.

## Поддержка продакшена

PageFlow намеренно не имеет производственной среды выполнения. Производственные сборки не должны содержать его клиент или конечные точки разработки.

## Политика версий

Диапазоны peer-зависимостей фреймворков описывают границы поддерживаемой интеграции. Перед использованием новых основных версий проверяйте манифест пакета и CI.

# Next.js

Next.js не предоставляет интерфейс плагина Vite, поэтому PageFlow использует sidecar того же источника только для разработки.

## Подготовка PageFlow

Установите пакет как зависимость разработки и убедитесь, что приложение Next.js запущено.

```bash
pnpm add -D unplugin-pageflow
pnpm next dev
```

## Запуск sidecar

Запустите CLI из корня приложения:

```bash
pageflow-next --dir . --host 127.0.0.1 --port 3000
```

CLI обнаружит поддерживаемые файловые маршруты Next.js и выведет URL PageFlow.

## Параметры

- `--dir` задаёт каталог проекта Next.js.
- `--host` задаёт хост разработки.
- `--port` указывает порт разработки Next.js, используемый sidecar.

## Только для разработки

Sidecar не является частью `next build` и не используется производственным сервером. Храните его в локальных сценариях разработки, а не в определениях производственных процессов.

## Устранение неполадок

- Запустите Next.js до открытия превью страниц.
- Используйте доступные хост и порт.
- Убедитесь, что страницы напрямую отображаются в той же сессии браузера.
- Используйте локальную или тестовую аутентификацию и данные.

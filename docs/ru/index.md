## Больше страниц — меньше видимости

По мере роста приложения никто не видит его целиком в одном месте. Разработчики читают файлы маршрутов, дизайнеры сверяются с макетами, тестировщики идут по сценариям, и каждый держит часть потока в голове. Эти представления быстро расходятся.

PageFlow читает работающее приложение и размещает рядом его реальные страницы и ссылки. Один экран показывает, что существует, куда могут перейти пользователи и у каких страниц есть тесты.

## Запуск за несколько минут

```bash
pnpm add -D unplugin-pageflow
```

Добавьте PageFlow в конфигурацию разработки, запустите приложение и откройте URL, выведенный плагином.

# Работа с холстом

Холст PageFlow предназначен для изучения графа маршрутов, а не для редактирования данных приложения.

## Перемещение и масштабирование

- Прокручивайте или используйте трекпад для масштабирования вокруг указателя.
- Перетаскивайте пустое место холста, чтобы двигать область просмотра.
- Выберите карточку страницы, чтобы сфокусироваться на ней и увидеть связи.
- Используйте элементы управления viewport, чтобы сравнить мобильное и настольное превью.

## Фокус на странице

При выборе страницы связанные страницы попадают в область просмотра, выбранное превью становится активным iframe и появляются активные области навигации. Сфокусированный вид полезен, когда полный граф содержит больше контекста, чем требуется.

## Изучение групп маршрутов

Маршруты с общими сегментами пути могут отображаться колодой. Откройте её, чтобы перейти на следующий уровень. PageFlow сохраняет навигационную цепочку активной группы и анимирует переходы, помогая не потерять контекст.

## Чтение связей

Связи направлены. Исходящая линия означает, что на исходной странице есть известный способ перейти к цели. Отсутствие линии не всегда означает невозможность перехода: вычисляемые цели обнаруживаются только после того, как приложение их покажет.

## Обновление превью

PageFlow обновляет устаревшие страницы через ограниченную очередь. Выбранная и видимые страницы имеют приоритет. Изменения маршрутов и ссылок поступают через HMR, а существующие миниатюры остаются до готовности новых.

## Советы

- Начинайте с главной страницы или основного входного маршрута.
- В больших приложениях открывайте по одной группе маршрутов.
- Используйте тестовые данные перед фокусировкой страниц, записывающих данные при инициализации.
- Если страница не становится готовой, добавьте [явный сигнал готовности](/ru/reference/configuration#готовность-превью).

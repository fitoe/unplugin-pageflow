# Динамические маршруты

Маршрут вроде `/products/:id` нельзя отобразить, пока PageFlow не знает безопасное значение `id`. Укажите подходящие значения через `dynamicParams`.

```ts
PageFlow.vite({
  dynamicParams: {
    '/products/:id': { id: 'demo-product' },
    '/users/:userId/orders/:orderId': {
      userId: 'alice',
      orderId: 'order-100',
    },
  },
})
```

## Сопоставление

Используйте шаблон маршрута, предоставленный адаптером фреймворка, как ключ объекта. Каждый именованный параметр шаблона должен иметь значение.

## Строки запроса и хеши

PageFlow сохраняет найденные строки запроса и хеши как позиции навигации. Они могут обозначать вкладки, фильтры или якоря, пока базовый маршрут остаётся тем же.

```text
/products/demo-product?tab=history#activity
```

## Выбор примеров

Используйте стабильные идентификаторы из локальных фикстур или тестовых данных. Избегайте реальных идентификаторов клиентов и страниц, способных выполнить необратимую запись при инициализации.

Динамические параметры только создают URL. Они не обходят аутентификацию, авторизацию, загрузчики или проверку приложения.

## Устранение проблем

Если динамическая страница всё ещё не отображается:

1. Убедитесь, что ключ точно совпадает с шаблоном маршрута фреймворка.
2. Укажите все обязательные параметры.
3. Откройте созданный URL напрямую в той же сессии браузера.
4. Проверьте, не перенаправляет ли запрос аутентификация или загрузчик.

## Più pagine, meno visibilità

Quando un'app cresce, nessuno riesce a vederla interamente in un solo posto. Gli sviluppatori leggono i file delle rotte, i designer consultano i mockup, i tester seguono i casi di test e ognuno conserva una parte del flusso nella propria testa. Queste visioni divergono rapidamente.

PageFlow legge l'app in esecuzione e dispone insieme le pagine e i collegamenti reali. Una sola vista mostra cosa esiste, dove possono andare gli utenti e quali pagine hanno test.

## Inizia in pochi minuti

```bash
pnpm add -D unplugin-pageflow
```

Aggiungi PageFlow alla configurazione di sviluppo, avvia l'applicazione e apri l'URL mostrato dal plugin.

# 자주 묻는 질문

## PageFlow는 프로덕션에서 실행되나요?

아니요. PageFlow는 개발 도구입니다. 런타임과 엔드포인트는 프로덕션 빌드에서 제외됩니다.

## 라우터나 테스트 러너를 대체하나요?

아니요. 지원되는 통합에서 라우트를 읽고 사용자가 명시적으로 설정한 테스트 명령만 실행합니다.

## 인증을 우회할 수 있나요?

아니요. 미리보기는 현재 브라우저 세션과 애플리케이션의 일반 권한 검사를 사용합니다.

## PageFlow가 모든 컨트롤을 자동으로 클릭하나요?

아니요. 지원되는 탐색 대상을 감지하지만 컨트롤을 자동으로 클릭해 제품 전체를 크롤링하지는 않습니다.

## 계산된 대상이 없는 이유는 무엇인가요?

런타임에 조합되는 대상은 관련 상호작용이 일어나기 전까지 존재하지 않을 수 있습니다. 지원되는 링크를 사용하거나 프레임워크 어댑터가 허용하는 경우 명시적 힌트를 제공하세요.

## 미리보기가 데이터를 변경할 수 있나요?

애플리케이션 초기화 코드는 계속 실행됩니다. 미리보기 모드는 제어된 프레임에서 앵커 탐색과 폼 제출을 차단하지만 초기화 부작용까지 막을 수는 없습니다. 로컬 또는 테스트 데이터를 사용하세요.

## 썸네일은 어디에 저장되나요?

영구 썸네일은 `.unplugin-pageflow/cache`에 저장됩니다. 개발 서버가 중지된 상태에서는 이 디렉터리를 안전하게 삭제할 수 있습니다.

## 어떤 프레임워크를 지원하나요?

현재 [호환성 표](/ko/reference/compatibility)를 확인하세요.

## 버그는 어떻게 신고하나요?

프레임워크, 버전, 최소 설정, 라우트 패턴, 관련 콘솔 출력을 포함해 [GitHub](https://github.com/fitoe/unplugin-pageflow/issues)에 issue를 등록하세요.

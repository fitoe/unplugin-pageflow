# 동적 라우트

`/products/:id` 같은 라우트는 PageFlow가 `id`의 안전한 값을 알아야 렌더링할 수 있습니다. `dynamicParams`로 대표 값을 설정하세요.

```ts
PageFlow.vite({
  dynamicParams: {
    '/products/:id': { id: 'demo-product' },
    '/users/:userId/orders/:orderId': {
      userId: 'alice',
      orderId: 'order-100',
    },
  },
})
```

## 일치 규칙

프레임워크 어댑터가 노출하는 라우트 패턴을 객체 키로 사용합니다. 패턴에 필요한 이름 있는 매개변수마다 값을 제공해야 합니다.

## 쿼리 문자열과 해시

PageFlow는 발견한 쿼리 문자열과 해시를 탐색 위치로 유지합니다. 기본 라우트는 같아도 탭, 필터 또는 앵커를 나타낼 수 있습니다.

```text
/products/demo-product?tab=history#activity
```

## 예시 값 선택하기

로컬 fixture 또는 테스트 데이터가 뒷받침하는 안정적인 식별자를 사용하세요. 프로덕션 고객 ID와 초기화 중 되돌릴 수 없는 쓰기를 수행할 수 있는 페이지는 피해야 합니다.

동적 매개변수는 URL만 구성합니다. 인증, 권한 부여, 로더 또는 애플리케이션 유효성 검사를 우회하지 않습니다.

## 문제 해결

동적 페이지가 여전히 렌더링되지 않는 경우:

1. 설정 키가 프레임워크 라우트 패턴과 정확히 일치하는지 확인합니다.
2. 필요한 모든 매개변수를 제공합니다.
3. 같은 브라우저 세션에서 생성된 URL을 직접 엽니다.
4. 인증 또는 로더가 요청을 리디렉션하는지 확인합니다.

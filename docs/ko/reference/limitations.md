# 제한 사항과 안전

PageFlow는 개발 중 실제 애플리케이션 페이지를 렌더링합니다. 미리보기를 로컬 애플리케이션의 일반 방문처럼 다루세요.

## PageFlow가 하는 일

- 선택한 프레임워크 어댑터가 노출하는 라우트를 찾습니다.
- 동일 출처 페이지 미리보기를 렌더링합니다.
- 지원되는 링크와 탐색 대상을 감지합니다.
- 미리보기 모드 안에서 앵커 탐색과 폼 제출을 차단합니다.
- 런타임을 프로덕션 빌드에서 제외합니다.

## PageFlow가 하지 않는 일

- 인증이나 권한 부여를 우회하지 않습니다.
- 컨트롤을 자동으로 클릭하지 않습니다.
- 애플리케이션 시작 부작용을 억제하지 않습니다.
- 관련 상호작용 전에 모든 계산된 대상을 추론할 수 없습니다.
- Astro island 프레임워크 내부를 분석하지 않습니다.

## 안전한 데이터 사용

초기화 중 쓰기 작업을 하는 페이지에는 로컬 또는 테스트 데이터를 사용하세요. 실제 비밀번호, 토큰, 인증 코드나 기타 비밀을 미리보기 상태로 설정하지 마세요.

인증과 라우트별 상태는 현재 브라우저 세션에서 가져옵니다. 권한이 없는 페이지는 일반 로그인 또는 접근 거부 화면을 렌더링할 수 있습니다.

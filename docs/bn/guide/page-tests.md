# পৃষ্ঠার পরীক্ষা

PageFlow রুটকে ইউনিট, কম্পোনেন্ট ও এন্ড-টু-এন্ড পরীক্ষার সঙ্গে যুক্ত করে নির্বাচিত পৃষ্ঠা থেকে স্পষ্টভাবে কনফিগার করা কমান্ড চালাতে পারে।

## স্বয়ংক্রিয় সংযোগ

পরীক্ষা কোনো পৃষ্ঠা কম্পোনেন্ট import করলে, একই নামের নিয়ম মানলে বা টেস্ট কেসে সম্পূর্ণ রুটে গেলে যুক্ত হতে পারে। PageFlow প্রতিটি সংযোগের কারণ দেখায়।

## স্পষ্ট ম্যাপিং

স্বয়ংক্রিয় সংযোগ অস্পষ্ট হলে রুট ও ফাইল glob ব্যবহার করুন।

```ts
PageFlow.vite({
  pageTests: {
    '/orders/**': ['tests/orders-*.spec.ts'],
  },
})
```

## টেস্ট কমান্ড

ডিফল্টভাবে কোনো কমান্ড অনুমান বা সক্রিয় হয় না। প্রতিটি সমর্থিত টেস্ট ধরন স্পষ্টভাবে কনফিগার করুন।

```ts
PageFlow.vite({
  testCommands: {
    unit: {
      command: 'pnpm',
      args: ['vitest', 'run', '{file}', '-t', '{name}'],
    },
    component: {
      command: 'pnpm',
      args: ['vitest', 'run', '{file}', '-t', '{name}'],
    },
    e2e: {
      command: 'pnpm',
      args: ['playwright', 'test', '{file}', '-g', '{name}'],
      timeoutMs: 180_000,
    },
  },
})
```

`{file}` ও `{name}` ইনডেক্স করা মান দিয়ে প্রতিস্থাপিত হয়। কমান্ড প্রকল্পের রুট থেকে `shell: false` দিয়ে চলে। ডিফল্ট টাইমআউট ১২০ সেকেন্ড; `timeoutMs` ১ সেকেন্ড থেকে ৩০ মিনিট গ্রহণ করে।

## ফলাফল

পৃষ্ঠা প্যানেল অজানা, চলছে, সফল, ব্যর্থ, বাদ বা বাতিল অবস্থা দেখায়। চলমান পরীক্ষা PageFlow থেকে বাতিল করা যায়। টেস্ট আউটপুট শুধু ডেভেলপমেন্টে থাকে, প্রোডাকশন বান্ডলে যায় না।

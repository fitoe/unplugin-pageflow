# ডায়নামিক রুট

PageFlow `id`-এর নিরাপদ মান না জানা পর্যন্ত `/products/:id`-এর মতো রুট রেন্ডার করতে পারে না। `dynamicParams` দিয়ে প্রতিনিধিত্বমূলক মান কনফিগার করুন।

```ts
PageFlow.vite({
  dynamicParams: {
    '/products/:id': { id: 'demo-product' },
    '/users/:userId/orders/:orderId': {
      userId: 'alice',
      orderId: 'order-100',
    },
  },
})
```

## মিল

অবজেক্টের কী হিসেবে ফ্রেমওয়ার্ক অ্যাডাপ্টারের প্রকাশিত রুট প্যাটার্ন ব্যবহার করুন। প্যাটার্নের প্রতিটি নামযুক্ত প্যারামিটারের একটি মান থাকা দরকার।

## কুয়েরি স্ট্রিং ও হ্যাশ

PageFlow আবিষ্কৃত কুয়েরি স্ট্রিং ও হ্যাশ নেভিগেশন অবস্থান হিসেবে রাখে। মূল রুট একই রেখে এগুলো ট্যাব, ফিল্টার বা অ্যাঙ্কর প্রকাশ করতে পারে।

```text
/products/demo-product?tab=history#activity
```

## নমুনা মান নির্বাচন

লোকাল ফিক্সচার বা টেস্ট ডেটাসমর্থিত স্থিতিশীল পরিচয় ব্যবহার করুন। প্রোডাকশন গ্রাহক ID এবং ইনিশিয়ালাইজেশনে অপরিবর্তনীয় ডেটা লিখতে পারে এমন পৃষ্ঠা এড়িয়ে চলুন।

ডায়নামিক প্যারামিটার কেবল URL তৈরি করে। এগুলো অথেনটিকেশন, অথরাইজেশন, লোডার বা অ্যাপ্লিকেশন ভ্যালিডেশন এড়ায় না।

## সমস্যা সমাধান

ডায়নামিক পৃষ্ঠা এখনও রেন্ডার না হলে:

1. কনফিগার করা কী ফ্রেমওয়ার্ক রুট প্যাটার্নের সঙ্গে হুবহু মেলে কিনা দেখুন।
2. প্রয়োজনীয় সব প্যারামিটার দিন।
3. একই ব্রাউজার সেশনে তৈরি URL সরাসরি খুলুন।
4. অথেনটিকেশন বা লোডার রিকোয়েস্ট রিডাইরেক্ট করছে কিনা দেখুন।

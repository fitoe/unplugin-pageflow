# সামঞ্জস্য

PageFlow-এর জন্য Node.js 20.19 বা নতুন দরকার। ডেভেলপমেন্ট ডিপেন্ডেন্সি হিসেবে ইনস্টল করুন।

| ইন্টিগ্রেশন | ন্যূনতম peer সংস্করণ | রুট উৎস | মন্তব্য |
| --- | --- | --- | --- |
| Vite + Vue Router | Vite 5, Vue 3.4, Vue Router 4 | `router.getRoutes()` | সম্পূর্ণ ডেভেলপমেন্ট রানটাইম ইন্টিগ্রেশন। |
| Nuxt | Nuxt 3 | Vue Router রেকর্ড | Nuxt/Vue নেভিগেশন ইভেন্ট শনাক্ত করে। |
| Astro | Astro 5 | ফাইল রুট | একই-অরিজিন অ্যাঙ্কর ও `data-pageflow-to`; island-এর ভেতর নয়। |
| React Router | রুট অবজেক্ট | স্পষ্ট রুট অবজেক্ট | `unplugin-pageflow/react-router` ব্যবহার করুন। |
| SvelteKit | SvelteKit 2 | ফাইল রুট | অ্যাডাপ্টার `sveltekit()`-এর সঙ্গে যুক্ত হয়। |
| SolidStart | SolidStart | ফাইল রুট | অ্যাডাপ্টার Solid প্লাগইনের সঙ্গে যুক্ত হয়। |
| Qwik City | Qwik 1.10, Qwik City 1.10 | ফাইল রুট | অ্যাডাপ্টার Qwik City ও Vite-এর সঙ্গে যুক্ত হয়। |
| Next.js | Next.js 15 | ফাইল রুট | `pageflow-next` ডেভেলপমেন্ট sidecar ব্যবহার করে। |
| uni-app | বর্তমান Vite-ভিত্তিক সেটআপ | তৈরি রুট | শুধু ডেভেলপমেন্ট। |

## ব্রাউজার প্রয়োজনীয়তা

পৃষ্ঠা প্রিভিউয়ের জন্য একই-অরিজিন iframe অ্যাক্সেস এবং স্ট্যান্ডার্ড history, messaging ও canvas সমর্থিত আধুনিক ব্রাউজার দরকার।

## প্রোডাকশন সমর্থন

PageFlow-তে ইচ্ছাকৃতভাবে প্রোডাকশন রানটাইম নেই। প্রোডাকশন বিল্ডে এর ক্লায়েন্ট বা ডেভেলপমেন্ট এন্ডপয়েন্ট থাকা উচিত নয়।

## সংস্করণ নীতি

ফ্রেমওয়ার্ক peer রেঞ্জ সমর্থিত ইন্টিগ্রেশনের সীমা জানায়। নতুন প্রধান ফ্রেমওয়ার্ক সংস্করণ নেওয়ার সময় প্যাকেজ ম্যানিফেস্ট ও CI দেখুন।

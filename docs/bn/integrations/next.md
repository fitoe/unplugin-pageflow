# Next.js

Next.js Vite প্লাগইন ইন্টারফেস দেয় না, তাই PageFlow শুধু ডেভেলপমেন্টে একই-অরিজিন sidecar ব্যবহার করে।

## PageFlow প্রস্তুত করুন

প্যাকেজটি ডেভেলপমেন্ট ডিপেন্ডেন্সি হিসেবে ইনস্টল করুন এবং Next.js অ্যাপ চলছে কিনা নিশ্চিত করুন।

```bash
pnpm add -D unplugin-pageflow
pnpm next dev
```

## sidecar চালু করুন

অ্যাপ্লিকেশনের রুট থেকে CLI চালান:

```bash
pageflow-next --dir . --host 127.0.0.1 --port 3000
```

CLI সমর্থিত Next.js ফাইল রুট আবিষ্কার করে PageFlow URL দেখায়।

## অপশন

- `--dir` Next.js প্রকল্প ডিরেক্টরি বেছে নেয়।
- `--host` ডেভেলপমেন্ট হোস্ট বেছে নেয়।
- `--port` sidecar সেটআপে ব্যবহৃত Next.js ডেভেলপমেন্ট পোর্ট নির্ধারণ করে।

## শুধু ডেভেলপমেন্ট

sidecar `next build`-এর অংশ নয় এবং প্রোডাকশন সার্ভার ব্যবহার করে না। এটি প্রোডাকশন প্রক্রিয়ার সংজ্ঞায় নয়, লোকাল ডেভেলপমেন্ট স্ক্রিপ্টে রাখুন।

## সমস্যা সমাধান

- পৃষ্ঠা প্রিভিউ খোলার আগে Next.js চালু করুন।
- ব্যবহারযোগ্য হোস্ট ও পোর্ট নিন।
- একই ব্রাউজার সেশনে পৃষ্ঠা সরাসরি রেন্ডার হয় কিনা দেখুন।
- লোকাল বা টেস্ট অথেনটিকেশন ও ডেটা ব্যবহার করুন।

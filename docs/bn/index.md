## পৃষ্ঠা বেশি, দৃশ্যমানতা কম

অ্যাপ বড় হলে কেউই পুরোটা এক জায়গায় দেখতে পায় না। ডেভেলপার রুট ফাইল পড়ে, ডিজাইনার মকআপ দেখে, টেস্টার টেস্ট কেস অনুসরণ করে—আর প্রত্যেকে প্রবাহের একটি অংশ মনে রাখে। এসব ধারণা দ্রুত আলাদা হয়ে যায়।

PageFlow চলমান অ্যাপ পড়ে তার আসল পৃষ্ঠা ও লিংক একসঙ্গে সাজায়। একটি দৃশ্যেই কী আছে, ব্যবহারকারী কোথায় যেতে পারে এবং কোন পৃষ্ঠায় পরীক্ষা আছে তা বোঝা যায়।

## কয়েক মিনিটে শুরু করুন

```bash
pnpm add -D unplugin-pageflow
```

ডেভেলপমেন্ট কনফিগারেশনে PageFlow যোগ করুন, অ্যাপ চালু করুন, তারপর প্লাগইনের দেখানো URL খুলুন।

[শুরু করার নির্দেশিকা পড়ুন →](/bn/guide/getting-started)

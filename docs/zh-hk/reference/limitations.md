# 限制與安全

PageFlow 在開發期間渲染真實應用頁面。請把預覽視為正常存取本機應用。

## PageFlow 會做甚麼

- 探索所選框架配接器公開的路由。
- 渲染同源頁面預覽。
- 探索受支援的連結和導航目標。
- 在預覽模式中阻止錨點導航和表單提交。
- 從正式版本排除自身執行階段。

## PageFlow 不會做甚麼

- 不會繞過驗證或授權。
- 不會自動點擊控制項。
- 不會抑制應用啟動副作用。
- 無法在相關互動前推斷所有計算出的目標。
- 不會檢查 Astro island 框架內部。

## 使用安全資料

對於初始化時會執行寫入的頁面，請使用本機或測試資料。不要把真實密碼、Token、驗證碼或其他機密設定為預覽狀態。

驗證和路由特定狀態來自目前瀏覽器工作階段。沒有權限的頁面可能顯示正常的登入或拒絕存取介面。

# 大型專案與快取

PageFlow 不會同時將所有路由渲染為即時文件。它的渲染與快取策略具有固定上限，讓大型圖仍然可以流暢探索。

## 視窗渲染

只會掛載附近的 DOM 預覽和 LeaferJS 場景物件。遠處頁面使用精簡表示，選中的單一頁面則提升為即時 iframe。

## 縮圖層級

附近頁面可以使用詳細預覽。遠處頁面使用精簡的 WebP 縮圖，長頁面也可以拆分成按視窗掛載的圖塊。重新擷取期間，過期縮圖仍會保持可見。

## 擷取佇列

PageFlow 會在擷取前等待字型、圖片和穩定的 DOM。工作每次處理一個頁面，選中及可見頁面具有較高優先級。

## 版面與查找

超過 1,000 個頁面的圖可以把版面配置工作移到 Worker。空間索引可尋找可見頁面，無需在每次視窗更新時掃描整個圖。

## 快取位置

持久縮圖儲存在：

```text
.unplugin-pageflow/cache
```

記憶體和磁碟快取使用固定的 LRU 預算。這個目錄是可刪除的開發輸出，需要完全重新擷取時可以移除。

## 實用建議

- 使用有意義的路徑片段來組織路由。
- 為動態參數提供穩定的範例值。
- 使用 fixture 資料讓預覽頁面保持確定性。
- 為長時間執行的非同步頁面使用就緒訊號。

## Mehr Seiten, weniger Überblick

Mit dem Wachstum einer App verliert jeder den Gesamtüberblick. Entwickler lesen Routendateien, Designer prüfen Entwürfe, Tester folgen Testfällen – und jeder trägt einen Teil des Ablaufs im Kopf. Diese Ansichten laufen schnell auseinander.

PageFlow liest die laufende App und ordnet ihre echten Seiten und Verbindungen gemeinsam an. Eine Ansicht zeigt, was existiert, wohin Nutzer gelangen können und welche Seiten getestet sind.

## In wenigen Minuten starten

```bash
pnpm add -D unplugin-pageflow
```

PageFlow zur Entwicklungskonfiguration hinzufügen, die Anwendung starten und anschließend die vom Plugin ausgegebene URL öffnen.

# 使用画布

PageFlow 画布用于探索路由关系，不会直接编辑应用数据。

## 移动与缩放

- 使用滚轮或触控板，以指针位置为中心缩放。
- 拖动画布空白区域移动视野。
- 选择页面卡片，聚焦该页面及其关系。
- 切换预览尺寸，对比移动端与桌面端页面。

## 聚焦页面

选择页面后，相关页面会进入视野，当前预览会升级为实时 iframe，同时显示导航热点。当完整关系图信息过多时，聚焦视图能帮助你缩小范围。

## 浏览路由组

拥有相同路径层级的页面可能被折叠成页面组。打开页面组查看下一层，使用面包屑返回上级。切换层级时的动画用于保持空间上下文。

## 阅读连接

连接具有方向。出线代表当前页面存在通往目标页面的已知方式。没有连线不一定表示无法跳转：动态计算的目标只有在应用暴露后才会出现。

## 刷新预览

PageFlow 使用有界队列捕获过期页面，并优先处理当前选中和可见页面。路由与链接变化通过 HMR 更新，旧缩略图会一直保留到新版本就绪。

## 使用建议

- 从首页或主要入口路由开始探索。
- 大型应用一次只进入一个路由组。
- 对初始化时执行写操作的页面使用测试数据。
- 页面长期未就绪时，添加[显式就绪信号](/reference/configuration#预览就绪信号)。

# 限制与安全

PageFlow 会在开发环境中渲染真实应用页面。请像对待正常访问本地应用一样对待这些预览。

## PageFlow 会做什么

- 发现所选框架适配器暴露的路由。
- 渲染同源页面预览。
- 检测支持的链接和导航目标。
- 在预览模式中阻止链接导航和表单提交。
- 确保其运行时代码不会进入生产构建。

## PageFlow 不会做什么

- 不会绕过身份认证或权限检查。
- 不会自动点击控件。
- 不会阻止应用初始化时产生的副作用。
- 无法在相关交互发生前推断所有动态计算的目标地址。
- 不会检查 Astro 框架岛内部的实现。

## 使用安全数据

对于初始化时会执行写操作的页面，请使用本地或测试数据。不要把真实密码、令牌、验证码或其他敏感信息配置为预览状态。

身份认证和路由状态来自当前浏览器会话。没有权限访问的页面会正常显示登录或拒绝访问界面。
